# Report Toys 2026

PWA и веб-приложение для учета игрушечных автоматов, инкассаций и расходов.

## Стек

- Cloudflare Workers
- D1
- PWA (WebManifest + service worker)

## Что реализовано

- API для точек, автоматов, инкассаций и расходов
- Запись инкассаций с указанием суммы, количества, комментария и инкассатора
- Журнал инкассаций с датой и временем
- Простая веб-страница для учета автоматов
- Структура базы для точек, автоматов, инкассаций и расходов

## Файлы

- `wrangler.toml` — конфигурация Cloudflare Workers
- `src/index.ts` — обработка API и отдача статики
- `public/index.html` — веб-интерфейс
- `public/manifest.webmanifest` — мета-информация для PWA
- `public/sw.js` — простой сервис-воркер для кэширования
- `d1/schema.sql` — схема базы данных
- `d1/seed.sql` — пример начальных данных

## Запуск локально

1. Установите зависимости:
   ```bash
   npm install
   ```
2. Войдите в Cloudflare:
   ```bash
   npx wrangler login
   ```
3. Запустите локальный дев-сервер:
   ```bash
   npx wrangler dev
   ```

## Настройка D1

1. Создайте базу D1:
   ```bash
   npx wrangler d1 create report_toys_2026
   ```
2. Примените схему:
   ```bash
   npx wrangler d1 apply --database report_toys_2026 d1/schema.sql
   ```
3. (Опционально) добавьте начальные точки и автоматы:
   ```bash
   npx wrangler d1 execute --database report_toys_2026 "$(cat d1/seed.sql)"
   ```

## Развертывание

1. Укажите `account_id` в `wrangler.toml`.
2. Опубликуйте:
   ```bash
   npx wrangler publish
   ```

## Адаптированный гайд (короткая справка)

Если потребуется развернуть проект по образцу Partner Ledger Dashboard, полезные шаги:

- Установите зависимости: `npm install`
- Локальная разработка: `npm run dev` (в этом репозитории настроен `wrangler dev --port 8787`)
- Для деплоя используйте: `npm run deploy` (или `npm run publish`)
- В `public/admin.html` подключены Google Fonts и Chart.js (через CDN) — можно заменить встроенные SVG-графики на Chart.js
- Для D1: создайте базу в Cloudflare, обновите `wrangler.toml` и выполните миграции из `d1/schema.sql`

Если хочешь, могу:
- заменить SVG-графики на Chart.js и подключить легенду/диапазон дат
- показать имена точек и автоматов в заголовках вместо ID
- добавить экспресс-скрипт миграций и пример `wrangler.toml` с env
